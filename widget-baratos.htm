Añade un buscador de ofertas a tu web o blog

Hemos preparado un widget de baratos.net para que puedas insertar un buscador de chollos, ofertas y códigos descuento en tu propia web usando un simple iframe.

Vista previa

Este es el widget funcionando en directo. Los resultados se abrirán en una nueva pestaña de baratos.net.

Si quieres ver la web completa, puedes entrar directamente en baratos.net.

Instalación rápida

Copia el bloque recomendado y pégalo en la zona HTML donde quieras mostrar el buscador.

  1. Copia el código del widget.
  2. Pégalo donde quieras mostrar el buscador.
  3. Publica los cambios en tu web.

Si tu editor visual toca el código, pégalo en un bloque HTML o en la plantilla de tu web.

Código recomendado

Este es el código recomendado para la mayoría de webs. Si no quieres complicarte, úsalo tal cual.

Abrir widget Ir a baratos.net

Opciones rápidas

Si quieres personalizar un poco el buscador, puedes cambiar estas opciones en la URL del widget:

  • theme=light o theme=dark para cambiar el estilo visual.
  • title=... para cambiar el título.
  • placeholder=... para cambiar el texto del buscador.
  • button=... para cambiar el texto del botón.

Si no quieres tocar nada, usa el código recomendado y listo.

Consejos de uso

  • Si lo pones en una columna estrecha, déjalo al 100% de ancho.
  • Si tu web tiene fondo oscuro, prueba theme=dark.
  • Si prefieres no tocar nada, usa el código recomendado tal cual.
  • Comprueba cómo queda en móvil y en escritorio antes de publicarlo.
