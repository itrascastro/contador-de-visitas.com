Añade un buscador de ofertas a tu web o blog

Hemos preparado un widget de baratos.net para que puedas insertar un buscador de chollos, ofertas y códigos descuento en tu propia web usando un simple iframe.

Si quieres ver la web completa, puedes entrar directamente en baratos.net.

Instalación rápida

Copia el bloque recomendado y pégalo en la zona HTML donde quieras mostrar el buscador. El ejemplo ya incluye el autoajuste de altura para que el iframe no se corte.

  1. Copia el código del widget.
  2. Pégalo donde quieras mostrar el buscador.
  3. Publica los cambios en tu web.

Si tu editor visual elimina scripts, tendrás que insertarlo en un bloque HTML o plantilla que permita JavaScript.

Parámetros de configuración

Puedes personalizar el widget modificando la URL del atributo src del iframe. Los parámetros soportados actualmente son estos:

  • theme=light o theme=dark: cambia el estilo visual del widget.
  • title=...: sustituye el título principal mostrado dentro del widget.
  • placeholder=...: cambia el texto del campo de búsqueda.
  • button=...: cambia el texto del botón.
  • campaign=...: etiqueta interna para medir desde qué inserción llega el tráfico.
  • target=top o target=self: controla dónde se abre el resultado. Si no lo indicas, se abre en una nueva pestaña.

Los antiguos parámetros host y base ya no se usan. Aunque se pasen en la URL, el widget abre siempre los resultados en baratos.net.

Consejos de uso

  • Si lo insertas en una sidebar estrecha, mantén el ancho al 100% y deja que el widget se adapte solo.
  • Si tu web tiene fondo oscuro, prueba theme=dark.
  • Si quieres que la búsqueda reemplace tu página actual, usa target=top.
  • Si prefieres no tocar nada, usa el código recomendado tal cual.

Notas importantes

  • Para que el iframe funcione correctamente, tu página debe servirse por http:// o https://. Abrir el HTML localmente con file:// no es una prueba fiable.
  • El widget envía un evento baratos-widget:resize al contenedor para ajustar su altura. Por eso el script del ejemplo es importante.
  • Si usas un CMS con bloque HTML personalizado, pega el código completo, no solo el iframe.
